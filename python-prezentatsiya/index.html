Python nima?

Python — o‘rganishga eng qulay dasturlash tillaridan biri. Matni oddiy, deyarli oddiy gapga o‘xshaydi.

# Kompyuterga: ekranga yoz

Bu 1 qator — ekranda “Salom, dunyo!” chiqadi. Boshqa tillarda ko‘pincha uzunroq bo‘ladi.

  • 1Oddiy yoziladi — o‘qish oson, qo‘rquv kam.

Muhim bo‘lim

Django nima?

Django = Python uchun veb “qurilish to‘plami”

Sayt yoki onlayn xizmat yasashda kerak bo‘ladigan tayyor qismlar: login, ma’lumotlar bazasi, admin panel, xavfsizlik…

Oddiy misol: lego. Python — g‘ishtlar. Django — tayyor to‘plam + yo‘riqnoma: uy (sayt) tezroq quriladi.
