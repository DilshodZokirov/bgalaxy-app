# 00 — Muhit

## O‘rnatish

1. Python 3.11+ — https://www.python.org/downloads/
2. Tekshiruv:

```bash
python3 --version
```

3. Birinchi fayl `hello.py`:

```python
print("Salom, Python!")
```

```bash
python3 hello.py
```

## REPL (interaktiv)

```bash
python3
>>> 2 + 2
4
>>> exit()
```

Bu yerda yozganingiz ham **shu interpreter** orqali bajariladi.

## O‘tdim

- [ ] `python3 --version` ishlaydi
- [ ] `hello.py` ishlaydi
- [ ] REPL ochib, bitta ifoda hisobladim
