Bitta papka. Yuklab oling — internetsiz ham o‘rganishingiz mumkin (darslar shu yerda).

## Qanday yuklab olish

**GitHub dan:**
1. Shu branch yoki PR ni oching
2. `Code` → `Download ZIP`
3. Yoki faqat shu papkani nusxalang: `python-0-100/`

**Terminal:**
```bash
# butun branchni
git clone -b cursor/python-takrorlash-5498 https://github.com/DilshodZokirov/bgalaxy-app.git
cd bgalaxy-app/python-0-100
```

## Qanday o‘qish

1. Avval **[ROADMAP.md](ROADMAP.md)** ni oching  
2. Foiz tartibida boring (0% → 100%)  
3. Har darsdan keyin `mashqlar/` ni ishga tushiring  
4. Qiynalsa `yechimlar/` — lekin avval o‘zingiz yozing  
5. Oxirida `loyihalar/` ni mustaqil yozing  

```bash
cd python-0-100
python3 mashqlar/m00_xotira.py
python3 mashqlar/run_all.py
```
