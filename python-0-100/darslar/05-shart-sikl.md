## if
```python
if ball >= 90:
    print("A")
elif ball >= 70:
    print("B")
else:
    print("C yoki F")
```

## for / while
```python
for i in range(5):
    print(i)

n = 3
while n > 0:
    print(n)
    n -= 1
```

`break` — to'xtatish, `continue` — keyingi aylanish.
