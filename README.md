# Python taqdimoti (boshlovchilar / bolalar uchun)

Dasturlashni hali bilmaydiganlar uchun sodda taqdimot.

## Ochish

Brauzerda oching:

```text
python-prezentatsiya/index.html
```

yoki:

```bash
cd python-prezentatsiya
python3 -m http.server 8080
# http://localhost:8080
```

## Boshqarish

| Tugma | Amal |
